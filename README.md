
# Cognifyz Number Patterns

## About the Project
A Python-based Number Patterns program developed as part of the Cognifyz Technologies Software Development Internship.

## Features
- Generates different number patterns.
- Uses loops and conditional statements.
- Accepts user input to control pattern size.
- Displays patterns in the terminal.

## Technologies Used
- Python
- For loops
- Conditional statements
- User input

## How to Run

```bash
python number_patterns.py
```
